# DevOps Internship Task 4: Git Workflow

## Objective
Manage a DevOps project using Git best practices and GitHub.

## Tools Used
- Git
- GitHub
- AWS EC2 Linux server

## Tasks Completed
1. Initialized a Git repository.
2. Created `main`, `dev`, and `feature` branches.
3. Added and committed project documentation.
4. Pushed branches to GitHub.
5. Practiced a pull request workflow.
6. Added a `.gitignore` file.
7. Created and pushed the `v1.0` Git tag.
8. Documented the workflow using Markdown.

## Git Commands Practiced
- `git init`
- `git branch`
- `git switch`
- `git add`
- `git commit`
- `git push`
- `git pull`
- `git tag`
- `git log`

## Conclusion
This project demonstrates basic Git version control, branching, commits, GitHub collaboration, ignore rules, and version tagging.
